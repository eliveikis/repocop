# ADR-020: The repo template doesn't assume code

**Status:** accepted · **Date:** 2026-09-29

## Context

An onboarded repository may produce software, writing or other media.

## Decision

The template's skills and rules fit all of these. Code-specific guidance is marked as such ("In code: …"), and each repository's `CLAUDE.md` names its own check command.

## Consequences

- Skills verify through the check command a repository documents, if it has one.
