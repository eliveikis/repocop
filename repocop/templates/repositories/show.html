How this works

Waiting: done, and its pull request still has to be merged and fetched; no other sync starts meanwhile. On origin: its files are on the default branch there. Not on origin: a newer sync or template change replaced it. Remove deletes a sync's branch and worktree on this machine, and only when its worktree has nothing uncommitted; a pushed branch and its pull request stay on GitHub. Removing a waiting sync drops it, so Sync offers its files again.
