# README

The README is the way in: what RepoCop is, how to install and start it, and where to read the rest. What another file owns, it links to rather than restates, since a copy drifts from its owner (`.claude/rules/principles.md`):

- settings, their defaults and where they're read from: `repocop.example.yaml`
- commands: `make help`; the host's tools and versions: `make doctor`
- a script's usage: the script's own header, such as `.reviews/review.sh`
- design, scope and non-goals: `specs/index.md` and the files it lists
- progress and status: nowhere but branches and pull requests (`.claude/rules/specs.md`)
